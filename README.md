💻 Device Management System

Operating Systems Mini Project | Python

📌 About Project

Device Management System is a Python-based mini project that simulates basic I/O device management operations in an Operating System.

✨ Features

- Add Device
- Remove Device
- View All Devices
- Search Device
- Allocate Device to User/Process
- Release Allocated Device

🛠️ Technologies Used

- Python
- Object-Oriented Programming (OOP)
- Visual Studio Code

▶️ How to Run

1. Download this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

py "device_management_system (1).py"

📂 Project Structure

Device-Management-System/
│
├── README.md
└── device_management_system (1).py

🎯 Project Objective

To understand how an Operating System manages I/O devices and their allocation to users or processes.
